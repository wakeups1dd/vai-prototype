# Maharashtra Board SSC (Class 10) Past Papers

## Folder Structure:

```
board-papers/
├── 2020/
├── 2021/
├── 2022/
├── 2023/
└── 2024/
```

## File Naming Convention:

Place PDF files in the respective year folders with these exact names:

### Science:
- `science1.pdf` - Science and Technology Part 1
- `science2.pdf` - Science and Technology Part 2

### Mathematics:
- `maths1.pdf` - Mathematics Part 1 (Algebra)
- `maths2.pdf` - Mathematics Part 2 (Geometry)

### Social Science:
- `history.pdf` - History and Political Science
- `geography.pdf` - Geography

### Languages:
- `english.pdf` - English (First Language)
- `hindi.pdf` - Hindi (Second/Third Language)
- `marathi.pdf` - Marathi (Second/Third Language)

## Example:

For 2024 Science Part 1 paper:
```
board-papers/2024/science1.pdf
```

For 2023 Mathematics Part 2 paper:
```
board-papers/2023/maths2.pdf
```

## Total Papers Expected:

- Per Year: 9 papers (all subjects)
- Total (2020-2024): 45 papers

## How to Add Papers:

1. Download official Maharashtra Board question papers
2. Rename them according to convention above
3. Place in correct year folder
4. Refresh the website
5. Papers will appear automatically

## Note:

The website will show error if paper PDF is not found. Users can still see the paper card but will get "File not found" message when trying to view/download.
